# 小羊机器学习

面向广大学生、研究生和机器学习爱好者的机器学习、深度学习与现代 AI 交互式学习站。

这个项目希望用更温和、系统、容易坚持的方式，帮助初学者从基础概念出发，逐步理解机器学习、深度学习、现代大模型应用、科研实验和大厂面试所需的核心知识。

如果这个项目对你有帮助，欢迎点一个 Star 多多支持，也欢迎继续补充案例、论文笔记、项目经验和学习心得。

## 在线内容

核心页面是：

- `index.html`：单文件离线学习站，打开即可阅读。
- `PRD.md`：产品需求设计文档，记录页面设计目标、内容范围和后续迭代方向。

## 内容覆盖

- 机器学习基础：数据、特征、标签、模型、损失函数、训练集、验证集、测试集、过拟合、泛化、评价指标。
- 经典算法：线性回归、逻辑回归、KNN、朴素贝叶斯、决策树、随机森林、GBDT、XGBoost、LightGBM、SVM、K-Means、PCA。
- 深度学习基础：神经网络、前向传播、反向传播、优化器、正则化、BatchNorm、LayerNorm、PyTorch 训练流程。
- 现代 AI：CNN、RNN、Attention、Transformer、自监督学习、Embedding、RAG、Agent、LoRA/QLoRA、多模态、扩散模型。
- 科研与论文：论文阅读、实验设计、baseline、消融实验、错误分析、科研启发和论文写作框架。
- 大厂面试：高频问题、项目表达模板、算法选型和真实业务场景分析。

## 适合谁

- 机器学习和深度学习刚入门的本科生、研究生。
- 想系统补 AI 基础的开发者和算法爱好者。
- 准备算法岗、机器学习工程师、AI 应用工程师面试的同学。
- 想把课程项目升级成论文或简历项目的学习者。

## 学习建议

1. 第一遍看直觉、例子和应用，不要卡在公式。
2. 第二遍补公式、代码和实验流程。
3. 第三遍重点看科研启发、论文写法和面试题。
4. 每学一个算法，都问自己三个问题：现在是什么，为什么还用，能解决什么真实需求。

## 本地预览

直接双击 `index.html` 即可打开。

也可以在仓库目录启动一个本地服务：

```bash
python -m http.server 8765
```

然后访问：

```text
http://127.0.0.1:8765/index.html
```
