02. 知识来源与学习方法

2014 的经典课程能当骨架，但 2026 的学习必须补上现代模型、工具链、科研范式和产业需求。

关键判断：基础不会过时，但讲法会过时。线性回归、逻辑回归、梯度下降、过拟合、偏差方差仍然是地基；Octave/Matlab 作为主实践工具、浅层网络作为终点、只看离线准确率，这些就明显不够了。
层级 内容 2026 学法
基础层 线性代数、概率统计、损失函数、梯度下降、过拟合、偏差方差 讲透直觉和公式，因为它们决定你能不能读懂论文、调好模型。
经典算法层 线性回归、逻辑回归、树模型、SVM、K-Means、PCA 作为 baseline、可解释模型和表格数据方案学习，重点是适用边界。
现代深度学习层 CNN、RNN、Attention、Transformer、自监督学习、预训练、微调 结合 PyTorch、论文结构和实验设计，不只背结构图。
大模型应用层 Embedding、RAG、Agent、LoRA/QLoRA、多模态、评测、部署 按任务和成本选择方案，重视事实性、引用、延迟、安全和可维护性。

03. 学前准备

不要等数学“全会了”再开始。先知道每块数学在模型里负责什么，遇到问题再补。

线性代数

现在是什么：表示数据和模型参数的语言。Embedding 是向量，图片是张量，神经网络大多是矩阵乘法堆出来的。

为什么用：没有矩阵思维，就很难理解批量训练、注意力矩阵、PCA 和神经网络参数。

概率统计

现在是什么：描述不确定性的语言。分类概率、贝叶斯方法、A/B 测试、置信区间、生成模型都离不开它。

为什么用：科研和业务不只问“准不准”，还问“结果稳不稳、可信不可信”。

微积分与优化

现在是什么：模型学习的方向盘。反向传播把错误拆回每个参数，优化器决定怎么修。

为什么用：学习率、梯度爆炸、AdamW、收敛曲线，本质都在优化里。

最小编程工具栈

Python：写实验脚本和数据处理。NumPy：理解数组和矩阵。Pandas：处理表格数据。Matplotlib：画 loss、指标和错例。scikit-learn：传统机器学习和评估。PyTorch：深度学习训练。Jupyter：探索和记录实验。

数学不用一次补完，但要知道它们分别在干什么

机器学习里的数学不是为了炫技，而是为了让你知道模型为什么能学、为什么会错、为什么调参会有效。研究生小白最容易犯的错是：要么完全躲开公式，要么陷入数学细节不敢开始。正确方式是先掌握“够用的数学地图”。

线性代数：数据的形状语言

一条样本可以看成一个向量，一批样本可以看成一个矩阵，图片和视频可以看成更高维张量。神经网络里大量计算都是矩阵乘法：输入矩阵乘以权重矩阵，再加偏置，再过激活函数。Transformer 的注意力也可以看成矩阵之间的相似度计算。

你需要先会：向量、矩阵乘法、转置、点积、范数、特征值/特征向量的直觉。PCA 为什么能降维，就是因为它在找数据变化最大的方向。

概率统计：不确定性的语言

模型输出 0.8，不是说“绝对正确”，而是说在模型看来属于这个类别的概率更高。最大似然、交叉熵、贝叶斯、置信区间、A/B 测试、概率校准，都来自概率统计。论文实验里只报告一次结果不够，因为训练有随机性，数据采样也有随机性。

你需要先会：均值、方差、条件概率、贝叶斯公式、常见分布、最大似然、置信区间。它们能帮你判断结果是否稳定，提升是否显著。

微积分：模型怎么知道往哪改

导数描述“一个变量变一点，结果会怎么变”。机器学习里损失函数对参数求导，就是在问：这个参数往上调一点，错误会变大还是变小？链式法则是反向传播的核心，因为深度网络是一层套一层的复合函数。

你需要先会：导数、偏导、梯度、链式法则。不要一开始追求推导所有复杂网络，只要先能看懂梯度下降为什么更新参数。

优化：训练模型就是找一个足够好的低点

训练模型可以想象成在山地里找低谷，低谷代表损失小。学习率太大可能一步跨过低谷，太小又走得太慢；模型太复杂可能在训练集低谷里陷得太深，到了真实数据就不好用。优化不只是数学问题，也和数据、模型结构、初始化、归一化、batch size 有关。

04. 机器学习基础

机器学习不是让电脑“有灵感”，而是让电脑从数据中学出可泛化的规律。

机器学习现在是什么

它是从数据中学习函数的技术体系：输入是特征，输出是预测，训练目标是让预测在未知数据上也可靠。2026 年你看到的大模型、推荐系统、风控模型、视觉检测，本质都继承了这套“数据、模型、损失、优化、评估”的骨架。

为什么还要先学它

因为论文实验、大厂面试和项目复盘都会回到底层问题：数据怎么划分，指标是否合理，是否过拟合，baseline 是什么，改进是否真的有效。不会基础，就只能调包，讲不清为什么。

训练集、验证集、测试集：像备考，但不能偷看答案

训练集像平时刷题，用来学习。验证集像模拟考试，用来选模型和调参数。测试集像正式考试，只能最后看一次。科研里如果反复拿测试集调模型，就等于把正式考试答案背熟了，论文结果会虚高。

欠拟合、过拟合、泛化：裁缝做衣服的类比

欠拟合像衣服做得太粗，谁穿都不合身；过拟合像只按一个人身材精修，换个人就不行；泛化能力就是这件衣服能适配新顾客的程度。深度学习和大模型微调也一样，训练集分数高不代表真实场景可靠。

指标 适合任务 真实需求提醒
Accuracy 类别均衡分类 样本极不均衡时可能骗人，比如 99% 都是正常样本。
Precision 误报代价高 垃圾邮件、风控拦截、医学阳性提醒都要看误报影响。
Recall 漏报代价高 疾病筛查、故障预警、欺诈检测更怕漏掉真正风险。
F1 Precision 与 Recall 都重要 适合类别不均衡的综合比较，但仍要结合业务代价。
ROC-AUC / PR-AUC 排序和阈值选择 极度不均衡时 PR-AUC 往往比 ROC-AUC 更有信息量。
MSE / MAE / RMSE 回归 MSE 更惩罚大错，MAE 更稳健，RMSE 单位和目标一致。
科研启发：如果同一个模型在 A 数据集很好、B 数据集很差，问题可能不是“模型不够大”，而是分布偏移、领域差异、标注噪声或指标不合适。这些都能发展成论文问题。

把机器学习任务拆开看：先别急着选模型

很多初学者一看到任务就问“用什么模型”，这一步太早。真正靠谱的顺序是：先定义任务，再看数据，再定指标，最后才选模型。比如“预测学生是否挂科”这个任务，如果学校最怕漏掉高风险学生，指标就不能只看 Accuracy，而应该重点看 Recall；如果误报会造成过度干预，就还要看 Precision。指标不同，模型选择和阈值都会变。

1. 任务类型决定学习范式

监督学习有明确标签，适合分类、回归、排序。无监督学习没有标签，适合聚类、降维、异常发现。自监督学习把数据自己构造成训练信号，比如遮住一句话里的词让模型猜，或者让相似样本的向量更接近。强化学习关心动作、环境、奖励，更像训练一个会试错的策略。

2. 特征不是越多越好

特征是模型看世界的窗口。窗口太少，模型看不清；窗口太乱，模型会被噪声骗。科研里常见的失败是：模型看起来很复杂，但输入特征本身没有任务信息。业务里常见的失败是：训练时用了未来信息，形成数据泄漏，离线结果很好，线上一塌糊涂。

3. 损失函数是“训练时的目标”，指标是“汇报时的目标”

训练时模型通常优化一个可微的损失函数，例如交叉熵或 MSE；汇报时我们看 Accuracy、F1、AUC、MAE 等指标。二者不一定完全一致。比如推荐系统可能训练点击率，但业务更关心停留时长、转化率和长期留存；论文中如果只报告一个指标，结论可能很片面。

4. 泛化是机器学习的灵魂

模型不是为了记住训练集，而是为了在未知数据上表现好。泛化能力受数据量、模型复杂度、正则化、训练策略、数据分布和标签质量共同影响。你写论文时，主结果表只能说明“在这些数据和指标上有效”；如果想证明方法更有价值，就要加跨数据集、噪声、少样本、消融和效率分析。

真实问题 机器学习表述 首选指标 容易踩坑
判断一张工业图片是否有缺陷 二分类或异常检测 Recall、Precision、F1 缺陷样本少，准确率会虚高；漏检比误检更严重。
预测明天某商品销量 回归或时间序列预测 MAE、RMSE、MAPE 节假日、促销、库存等外部因素会造成分布变化。
把论文按研究主题分组 文本聚类或主题建模 轮廓系数、人工一致性、下游检索效果 没有标签时不能只看聚类图好不好看。
企业文档问答 检索增强生成 检索召回、事实性、引用命中率 生成流畅不等于正确，引用必须能对上原文。

05. 经典机器学习算法

经典算法不是“旧东西”，而是 baseline、可解释性、表格数据、快速验证和面试表达的核心工具箱。

线性回归 Linear Regression

现在是什么回归任务最小可解释 baseline，也是理解损失函数、梯度下降和特征贡献的入口。
为什么用简单、稳定、可解释；小数据、科研探索、业务汇报中很有价值。
例子用面积、地段、楼龄预测房价；用温度、湿度、负载预测能耗。
科研启发如果线性不够，可研究特征交互、非线性核、可解释回归和不确定性估计。
预测：ŷ = w₁x₁ + w₂x₂ + ... + b
损失：MSE = (1/n) Σ(yᵢ - ŷᵢ)²

逻辑回归 Logistic Regression

现在是什么二分类 baseline、概率输出模型、可解释风控和广告预估的常用起点。
为什么用训练快、解释清楚，特征权重能告诉你哪些因素推高风险或点击概率。
例子判断邮件是否垃圾邮件；判断患者是否高风险；判断用户是否会点击广告。
科研启发可研究概率校准、类别不平衡、代价敏感学习和可解释特征选择。
p(y=1|x) = sigmoid(wᵀx + b) = 1 / (1 + e⁻ᶻ)

K 近邻 KNN

现在是什么基于相似性的懒学习方法，也是理解检索、Embedding 近邻搜索的前置直觉。
为什么用简单直观，不需要训练复杂模型，适合小规模相似样本判断。
例子根据相似病例辅助诊断；根据相似用户推荐内容；用向量相似找相近论文。
科研启发距离度量学习、近邻检索加速、表征质量评估都是现代研究方向。

朴素贝叶斯 Naive Bayes

现在是什么概率分类器，常作为文本分类和小数据任务 baseline。
为什么用快、稳、对高维稀疏文本友好。
例子垃圾邮件过滤、新闻主题分类、情感粗分类。
科研启发可讨论条件独立假设何时失效，如何引入特征依赖或不确定性估计。

决策树 Decision Tree

现在是什么可解释规则模型，像一串“如果...那么...”的问题。
为什么用人能读懂，适合规则提取、风控解释、医学分诊等场景。
例子银行根据收入、负债、信用记录做贷款初筛；医生根据症状做分诊建议。
科研启发可研究可解释模型、人机协同决策、规则蒸馏。

随机森林 Random Forest

现在是什么多棵决策树投票，降低单棵树过拟合和不稳定。
为什么用表格数据强、调参少、能看特征重要性。
例子用户流失预测、基因表达特征筛选、设备故障分类。
科研启发可研究特征重要性稳定性、小样本高维数据、可解释集成模型。

GBDT / XGBoost / LightGBM

现在是什么结构化数据里非常强的生产级方案，Boosting 思想是不断修正前面模型的错误。
为什么用在很多表格业务数据上，比盲目使用深度模型更稳、更省、更容易解释。
例子风控评分、广告点击率预估、销量预测、Kaggle 表格竞赛。
科研启发排序损失、自定义目标函数、模型蒸馏、树模型与深度表征融合。

支持向量机 SVM

现在是什么最大间隔分类器，在小样本、清晰边界和核方法场景仍有教学与实践价值。
为什么用理论漂亮，能用核函数处理非线性边界。
例子小样本文本分类、传统图像特征分类、科研数据初步分类。
科研启发核函数设计、小样本泛化、间隔理论和表示学习结合。

K-Means 聚类

现在是什么无监督分组方法，也是理解聚类、原型、向量空间结构的入口。
为什么用快速探索数据结构，给用户、样本、论文或细胞分群。
例子用户分群、论文主题聚类、图像颜色压缩、异常模式发现。
科研启发聚类数选择、无监督评估、表示学习后的聚类、弱监督标注。

PCA 主成分分析

现在是什么高维数据降维、可视化、压缩和去噪工具。
为什么用快速看数据主方向，减少维度，辅助解释变量结构。
例子基因表达数据可视化、传感器降噪、表格特征压缩。
科研启发低维流形、可解释降维、表征压缩、信息保留与任务性能的关系。

小样本、强解释需求 线性/逻辑回归、决策树 简单透明，便于讲清变量影响 一上来就用大模型或复杂深网

经典算法详细讲解：它们不是过时，而是承担不同角色

深度学习和大模型很强，但现实任务并不是“越大越好”。表格数据、小样本、强解释、快速验证、论文 baseline、业务部署成本，都会让经典算法继续有用。你要学会的是：看到任务后判断这个算法是不是合适，而不是背一个算法排名。

线性回归：最小但很重要的回归模型

线性回归假设目标值可以由特征加权相加得到。它的直觉像“给每个因素打一个影响分”：面积每增加 1 平方米房价增加多少，楼龄每增加一年房价减少多少，距离地铁越近价格如何变化。它现在常作为回归 baseline、可解释分析和实验 sanity check。

什么时候用：数据量不大、关系接近线性、需要解释变量影响、需要快速建立 baseline。什么时候不用：关系强非线性、特征交互复杂、异常值很多且没有处理。科研启发：可以研究非线性特征、鲁棒回归、不确定性估计和可解释性。

逻辑回归：名字有回归，实际常做分类

逻辑回归先做线性加权，再通过 sigmoid 把结果压到 0 到 1 之间，解释为“属于正类的概率”。它在 2026 年仍常用于风控、医疗风险、广告点击、用户流失等需要概率和解释的场景。它也是理解交叉熵、概率校准和分类阈值的好入口。

真实例子：医院希望预测患者是否高风险，逻辑回归不仅给出概率，还能解释哪些指标提高风险。边界：如果类别边界很复杂，单纯逻辑回归可能不够；如果特征质量差，换大模型也救不了。科研启发：类别不平衡、代价敏感学习、概率校准、公平性分析。

KNN：相似样本给你投票

KNN 几乎不训练模型，而是在预测时找到最相似的 K 个样本，看它们的标签。它的价值不只是一个传统算法，更是现代向量检索和 RAG 的直觉来源：当文本、图片、用户、商品都变成 Embedding 后，“找相似向量”就是一种 KNN 思维。

真实例子：论文助手根据向量相似度找到与当前论文最相近的研究；推荐系统根据相似用户或相似商品召回候选。边界：高维空间距离可能失效，大数据检索成本高，需要近似最近邻索引。科研启发：度量学习、向量索引、表征质量评估。

决策树：把判断过程写成一棵问题树

决策树像一套逐步提问的规则：收入是否大于某阈值？负债是否过高？历史是否违约？每次分裂都希望让子节点更“纯”。它最大的优点是可解释，缺点是单棵树容易过拟合，数据稍微变化树结构就可能变。

真实例子：银行贷款初筛、医学分诊、设备故障规则解释。边界：不要把单棵树当作最强预测器，它更适合理解规则。科研启发：可解释规则、人机协同、从复杂模型蒸馏出规则树。

随机森林：让很多棵树一起投票

随机森林通过“样本随机 + 特征随机”训练多棵树，再投票或平均。单棵树像一个容易偏执的专家，森林像多个专家共同判断。它降低方差，通常比单棵树稳定，也能提供特征重要性。

真实例子：基因表达数据中筛选重要基因，用户流失预测中解释哪些行为最关键。边界：模型比单棵树难解释，极高维稀疏文本上未必最好。科研启发：稳定性选择、特征重要性可信度、小样本高维建模。

GBDT / XGBoost / LightGBM：结构化数据常胜将军

Boosting 的核心是“不断补短板”：第一棵树犯错，第二棵树重点学它没学好的部分，后面的树继续修正。XGBoost 和 LightGBM 是工程化很强的 GBDT 变体，支持高效训练、正则化、缺失值处理和复杂特征关系。

真实例子：广告点击率预估、信用评分、销量预测、表格竞赛。为什么现在还用：很多企业核心数据是表格，树模型训练快、解释成本低、上线稳定。边界：非结构化文本、图片、音频通常需要深度表示。科研启发：树模型与神经网络融合、排序损失、模型压缩、自动特征工程。

SVM：最大间隔带来的泛化直觉

SVM 希望找到一条分界线，不只是把样本分开，还要让分界线离两边样本尽可能远。这个“间隔越大越稳”的思想很重要。核函数让 SVM 能在高维空间处理非线性问题。

真实例子：小样本文本分类、传统图像特征分类、科研数据初步建模。边界：大规模数据训练成本高，概率输出不如逻辑回归直接。科研启发：小样本泛化、核方法、间隔理论与深度表征结合。

K-Means：用中心点理解群体结构

K-Means 试图找到 K 个中心，让每个样本归到最近的中心。它很适合快速探索数据：用户是不是能分成几类？论文主题有没有自然分组？细胞表达是否出现不同亚群？

边界：需要先定 K，对异常值敏感，适合球状簇，不适合复杂形状。科研启发：聚类数选择、无监督评价、深度聚类、用聚类辅助伪标签。

PCA：找到数据变化最大的方向

PCA 把高维数据投影到少数主成分上，希望保留尽可能多的信息。它不是万能降维，但非常适合探索：高维数据是否有明显结构？噪声是否集中在低方差方向？不同类别是否能在二维投影上分开？

真实例子：基因表达可视化、传感器数据压缩、图像降噪、实验前的数据探索。边界：PCA 是线性的，复杂流形结构可能需要 t-SNE、UMAP 或深度表示。科研启发：表征压缩、可解释降维、信息保留与下游任务关系。

06. 深度学习基础

深度学习把“人工设计特征”的一部分工作交给模型，让模型从数据中学出多层表示。

神经元与层

一个神经元做加权求和再过激活函数；一层神经元学一种变换；多层叠起来就能表达复杂关系。MLP 是深度学习的最小积木。

前向传播

像流水线工厂：输入经过一层层加工，最后得到预测。每一层都把原始数据变成更适合任务的表示。

反向传播

像根据最终误差追责：输出错了多少，会沿着计算图倒推到每个参数，告诉它应该往哪个方向改。

组件 现在是什么 为什么用 常见坑
ReLU / GELU 激活函数，让网络表达非线性 没有激活，多层线性仍然等价于一层线性 Sigmoid 深层网络容易梯度消失
Cross Entropy 分类任务核心损失 鼓励正确类别概率更高 标签错误和类别不均衡会影响训练
Adam / AdamW 常用优化器 自适应学习率，训练更省心 学习率过大仍会崩，权重衰减要分清 Adam 和 AdamW
Dropout 正则化方法 让模型不要过度依赖某些神经元 训练和推理行为不同，别忘了 eval 模式
BatchNorm / LayerNorm 归一化方法 改善训练稳定性 小 batch 下 BatchNorm 可能不稳；Transformer 常用 LayerNorm

深度学习到底在学什么：从“人工特征”到“自动表征”

传统机器学习常常依赖人设计特征：文本用词频，图片用边缘和纹理，用户用统计行为。深度学习的变化是：模型可以从原始或半原始数据中逐层学表示。低层学简单模式，高层学复杂语义。例如 CNN 低层可能学边缘，高层学病灶形状；语言模型低层学词法句法，高层学语义和任务模式。

前向传播：把输入加工成预测

前向传播就是从输入到输出的一次计算。图像进入 CNN 后变成特征图，文本进入 Transformer 后变成上下文相关向量，最后分类头或生成头给出预测。你可以把它看成一条加工流水线：每一层都在把信息变得更适合当前任务。

损失函数：告诉模型错在哪里

损失函数不是数学装饰，而是训练目标。分类用交叉熵，是因为我们希望正确类别概率更高；回归用 MSE，是因为我们希望预测值离真实值更近；对比学习用对比损失，是因为我们希望相似样本更近、不相似样本更远。论文中的“新损失”往往意味着作者重新定义了模型应该重视什么。

反向传播：把错误分摊给每个参数

模型输出错了，不能只说“最后一层负责”。反向传播会利用链式法则，把损失对每个参数的影响算出来。梯度为正或为负，表示参数增大会让损失怎么变；梯度大小表示影响强弱。优化器再根据这些梯度更新参数。

优化器：怎么走下山路

SGD 像每一步只看当前坡度，简单但可能抖；Momentum 会记住过去方向，像带惯性下山；Adam 为不同参数自适应调整步长，训练更省心；AdamW 把权重衰减处理得更合理，是很多 Transformer 和大模型微调常用选择。调参时，学习率通常比模型结构小改动更关键。

正则化：让模型别把训练集背下来

Dropout、Weight Decay、数据增强、Early Stopping 都是在减少过拟合。小数据论文尤其要重视正则化，因为模型很容易把训练集记住。真实项目里，如果训练集分数很高但线上差，先看数据泄漏和分布偏移，再看正则化是否足够。

# PyTorch 训练循环的核心四步
for x, y in dataloader:
    pred = model(x)          # 1. 前向传播
    loss = loss_fn(pred, y)  # 2. 计算损失
    optimizer.zero_grad()
    loss.backward()          # 3. 反向传播
    optimizer.step()         # 4. 更新参数
科研启发：损失函数不是附属品，而是研究目标的数学表达。你想要类别更准、排序更好、表示更接近、生成更真实，往往对应不同损失和训练策略。

07. 现代 AI 模型

现代 AI 的主线是表征学习、预训练、迁移、检索增强、工具调用和可靠评测。

CNN：会看局部模式的模型

用处：图像分类、缺陷检测、医学影像、遥感识别。

科研启发：小样本视觉、跨设备泛化、可解释热力图、弱监督定位。

RNN / LSTM / GRU：早期序列建模工具

用处：时间序列、传感器状态、文本序列。

科研启发：长依赖困难可引出 Attention、Transformer 或状态空间模型。

Attention：在一堆信息里找重点

用处：文本匹配、机器翻译、视觉区域关注、跨模态对齐。

科研启发：重要证据定位、可解释性、长上下文效率。

Transformer：现代 AI 的通用骨架之一

用处：语言模型、视觉 Transformer、推荐序列、蛋白质建模、多模态模型。

科研启发：结构改造、长序列压缩、预训练任务、领域迁移。

Attention 权重像“资料重点标注”

颜色越深，表示当前 token 越关注那个位置。多头注意力就像多个专家从不同角度标重点。

2026 版能力 现在是什么 为什么用 科研启发
Embedding 把文本、图片、用户、商品变成向量 向量相似度能做检索、推荐、聚类和 RAG 表征质量、跨域泛化、相似度偏差
RAG 先检索外部知识，再让模型生成答案 降低幻觉，能引用资料，适合企业知识库和论文助手 检索质量、引用可信度、事实一致性、版本变化
Agent 模型做任务规划并调用工具 适合数据分析、代码修复、自动流程和科研助手 任务分解、工具可靠性、执行评测、安全边界
LoRA / QLoRA 参数高效微调方法 不用更新全部大模型参数，显存和成本更低 领域适配、小样本泛化、量化误差、模块选择
多模态 同时处理文本、图像、音频、视频等信息 真实任务往往不是单一文本或单一图片 跨模态对齐、弱监督标注、细粒度解释
扩散模型 生成式视觉的重要范式 能做图像生成、数据合成、修复和增强 可控生成、合成数据有效性、生成质量评估

Transformer、RAG、Agent：现代 AI 的三条主线

如果说经典机器学习回答的是“如何从特征到预测”，深度学习回答的是“如何自动学习表示”，那么 2026 年的现代 AI 还多了三个问题：如何利用大规模预训练知识，如何接入外部知识，如何让模型调用工具完成任务。

Transformer 为什么成了基础架构

Transformer 的核心是自注意力。它让序列里的每个位置都能直接看其他位置，从而建模长距离关系。RNN 处理长文本时信息要一步步传，远处信息容易衰减；Transformer 可以并行计算所有位置之间的关系，因此更适合大规模训练。多头注意力相当于多个视角：有的头看语法，有的头看实体，有的头看远距离依赖。

预训练与微调：先读万卷书，再做专项训练

预训练模型先在大规模数据上学习通用表示，再在具体任务上微调。BERT、GPT、ViT 等都遵循这个思路。对研究生来说，关键不是“我能不能从零训练一个大模型”，而是能不能合理使用预训练模型，设计任务数据、损失函数、评估指标和消融实验。

RAG：让模型回答前先查资料

RAG 的流程通常是：把文档切块，转成 Embedding，存入向量数据库；用户提问时，先检索相关片段，再把片段和问题一起交给大模型生成答案。它适合企业知识库、论文问答、法律条款、客服手册等知识密集场景。RAG 不是把所有文档塞进 prompt，而是把“找资料”和“组织语言”拆开。

RAG 常见失败：切块太碎导致上下文不完整；Embedding 模型不适合领域术语；检索召回了无关段落；生成答案没有忠实引用；文档版本更新后索引没同步。科研上可以研究检索质量、重排序、引用一致性、长文档问答和事实性评估。

Agent：模型从回答问题走向执行任务

Agent 不是一个神秘物种，本质是“模型 + 任务规划 + 工具调用 + 记忆/状态 + 结果检查”。比如科研 Agent 可以读 CSV、画图、跑统计检验、写实验摘要；代码 Agent 可以定位 bug、修改文件、运行测试。Agent 的难点不是让模型说得漂亮，而是让它每一步都可验证、可回滚、可控。

LoRA / QLoRA：低成本适配大模型

全量微调大模型成本很高，LoRA 的思路是冻结原模型，只在部分权重旁边加低秩适配矩阵，让模型用少量参数学习新任务。QLoRA 进一步结合量化，降低显存占用。它适合领域文本分类、专业问答、风格适配等场景，但如果数据质量差，LoRA 也只会更快地学坏。

多模态与扩散模型：从文本走向世界

多模态模型把文本、图像、音频、视频放进同一个语义空间，适合图文检索、视觉问答、医学影像报告和工业巡检。扩散模型则是生成图像的重要路线，可以做图像生成、修复、增强和合成数据。科研中要小心：合成数据看起来像真的，不代表对下游任务一定有帮助，必须用实验验证。

08. 实际需求与场景地图

学算法不是为了收藏名字，而是为了看到一个真实问题时知道怎么拆、用什么、怎么评估。

结构化数据：风控评分

输入：用户画像、交易记录、信用历史。输出：违约或欺诈风险。

推荐算法：逻辑回归、随机森林、LightGBM、校准模型。

指标：AUC、KS、Recall、坏账率、误杀率。

科研方向：类别不平衡、可解释风控、分布偏移、隐私保护学习。

计算机视觉：工业缺陷检测

输入：产线图片或视频。输出：是否有缺陷、缺陷位置。

推荐算法：CNN、Vision Transformer、异常检测、弱监督分割。

指标：Precision、Recall、mAP、IoU、漏检率。

科研方向：小样本、合成数据、跨设备泛化、可解释定位。

NLP：论文文本分类与信息抽取

输入：标题、摘要、正文。输出：主题类别、方法实体、数据集和指标。

推荐算法：TF-IDF + 线性模型、BERT、长文本 Transformer、RAG。

指标：F1、Exact Match、人工一致性。

科研方向：长文档理解、领域迁移、引用关系建模。

大模型应用：企业知识库问答

输入：内部文档和用户问题。输出：带引用的回答。

推荐算法：Embedding、向量检索、RAG、重排序、答案评测。

指标：检索召回、答案事实性、引用命中率、响应延迟。

科研方向：RAG 评测、幻觉抑制、版本感知检索、多跳问答。

科研数据：材料性能预测

输入：成分、结构、工艺参数。输出：强度、导电性、稳定性。

推荐算法：线性回归、GBDT、图神经网络、主动学习。

指标：MAE、RMSE、Top-K 命中率、实验验证成功率。

科研方向：小样本、高成本实验、可解释特征、主动采样。

推荐系统：召回与排序

输入：用户行为、商品内容、上下文。输出：候选列表和排序分数。

推荐算法：协同过滤、双塔模型、GBDT 排序、序列推荐、Embedding 检索。

指标：NDCG、Recall@K、CTR、转化率、留存。

科研方向：冷启动、公平性、长期收益、反馈回路。

从真实需求到模型方案：一套通用思考流程

实际项目不是先选 Transformer，也不是先打开 PyTorch，而是先把需求翻译成机器学习问题。这个翻译能力很重要，因为它决定你做出来的是“能用的系统”，还是“看起来很 AI 的演示”。

第一步：确认决策对象

你要预测的是一个用户、一张图片、一篇论文、一段时间序列，还是一次对话？决策对象不同，样本定义就不同。比如用户流失预测的样本是“某个用户在某个时间窗口的行为”，而不是用户表里随便一行。

第二步：确认输出形式

输出可以是类别、数值、排序、聚类、文本答案、检测框、分割掩码、异常分数。输出形式决定模型和指标。比如“找出最可能流失的 1000 个用户”更像排序问题，而不只是二分类问题。

第三步：确认错误代价

医学筛查漏掉患者和误报患者的代价不一样；风控放过欺诈和误杀正常用户的代价不一样；RAG 答案不完整和编造引用的代价也不一样。错误代价决定指标、阈值和产品策略。

第四步：从简单 baseline 开始

不要一开始就堆复杂模型。表格数据先试逻辑回归、随机森林、LightGBM；文本先试 TF-IDF + 线性模型和预训练模型；图像先试迁移学习；RAG 先把切块、检索、重排序和引用链路跑通。baseline 能帮你发现问题到底在数据、模型还是评估。

第五步：把项目升级成科研问题

如果 baseline 在大多数样本上好，但在少数场景失败，你可以研究鲁棒性和长尾问题；如果跨数据集表现下降，你可以研究领域自适应；如果模型准但无法解释，你可以研究可解释性；如果 RAG 常引用错误，你可以研究事实性评估和引用约束。

09. 训练、调参和实验方法

会训练模型只是第一步。研究生和工程师真正要会的是：证明模型为什么有效，以及失败时怎么查。

数据处理

清洗缺失值、异常值；标准化数值特征；处理类别不平衡；划分训练/验证/测试集；确认标签质量。

调参重点

学习率、batch size、网络深度、正则化、weight decay、dropout、scheduler、早停。

实验管理

固定随机种子，记录超参数，保存 checkpoint，画 loss 曲线，多次运行报告均值和方差。

消融实验：证明每个模块不是摆设

如果你论文里提出了一个模块 A，就要比较“完整模型”和“去掉 A 的模型”。如果性能明显下降，说明 A 有贡献；如果没变化，说明这个模块可能只是装饰。面试项目也一样，面试官会问：你加的优化到底有没有用？

错误分析：论文创新经常从错例里长出来

把预测错的样本拿出来看：是不是某类样本少？是不是标注噪声？是不是长尾类别？是不是训练集没有覆盖真实场景？这些错例能变成研究动机，比如小样本学习、鲁棒学习、领域自适应、异常检测。

现象 可能原因 下一步
训练集和验证集都差 欠拟合、特征弱、模型太简单 加特征、换模型、训练更久、检查标签
训练集好，验证集差 过拟合 正则化、数据增强、早停、减小模型、加数据
离线好，线上差 分布偏移、数据泄漏、指标不一致 重做数据切分，监控线上数据，做时间切分评估
指标高但业务不满意 指标选错、类别不均衡、错例代价不同 换指标，按业务代价设置阈值，做错例分析

一套完整实验应该怎么做

研究生写论文和大厂做项目都不能只交一个“最终准确率”。一个可信实验要能回答：数据从哪来，怎么处理，baseline 是什么，模型怎么训练，调了哪些参数，结果是否稳定，提升来自哪里，失败样本是什么。

1. 数据阶段：先防止结果虚高

划分数据时要考虑任务真实发生方式。时间序列任务不能随机打乱后切分，否则未来信息会泄漏到训练集；同一个用户的多条记录如果同时出现在训练和测试，也可能导致模型记住用户；医学影像里同一患者的多张图不能分到不同集合。数据划分错误，是很多“高分模型”无法上线的根源。

2. Baseline 阶段：先建立可信起点

baseline 不一定弱。表格数据可以从逻辑回归、随机森林、LightGBM 开始；图像任务可以从预训练 ResNet 或 ViT 开始；文本任务可以从 TF-IDF + 线性模型和 BERT 微调开始；RAG 任务可以从 BM25、Embedding 检索、重排序逐步加。没有 baseline，就无法证明你的方法有贡献。

3. 训练阶段：记录比“感觉”可靠

每次实验都记录随机种子、数据版本、模型版本、超参数、训练轮数、最佳 checkpoint、验证集指标、测试集指标。最好画训练/验证 loss 曲线。曲线比单个数字更有信息：它能告诉你模型是否还在学习、是否过拟合、是否学习率太大。

4. 消融阶段：把贡献拆开证明

如果你加了数据增强、注意力模块、新损失函数、重排序器，就要分别去掉它们，看性能变化。消融表里最有价值的不是“完整模型最高”，而是每个模块的作用能被解释。面试官也会追问：你的提升到底来自模型结构、数据处理、调参，还是只是训练更久？

5. 错误分析阶段：从失败里找下一篇论文

把错例按类型分组：长尾类别、低质量图片、歧义文本、领域术语、噪声标签、跨域样本、极端场景。每一类错误都可能对应一个研究方向。比如 RAG 答错可能不是生成模型差，而是检索没召回；医学影像错例可能集中在某家医院设备，说明存在域偏移。

10. 科研启发与论文选题

科研不是凭空想一个“新模块”，而是从真实失败、算法边界、数据限制和实验现象中找到问题。

从实际需求找问题

现有模型在哪些场景失败？哪些类别表现差？训练数据和真实数据是否不同？模型是否太慢、太大、太难解释？

从算法缺点找问题

线性模型表达弱，树模型难处理复杂文本，CNN 全局关系弱，RNN 长依赖困难，大模型容易幻觉。这些缺点就是选题入口。

从实验现象找问题

换数据集是否还有效？小样本是否有效？噪声标签是否稳定？缺少某类特征时是否鲁棒？计算量是否值得？

从论文贡献组织问题

新任务、新方法、新数据、新分析、新系统都可以是贡献，但必须能被实验验证，不是只换一个名字。

选题句式：在真实场景 X 中，现有方法 Y 因为 Z 表现不稳定。我们提出 A，通过 B 机制改善 C，并在 D 数据集上用 E 指标和消融实验证明有效。

11. 论文阅读与写作

读论文不是逐字翻译，而是抓住问题、方法、证据和局限。

第一遍：抓骨架

看标题、摘要、图、结论。回答：它解决什么问题？比谁好？好在哪里？

第二遍：看方法

看模型结构、损失函数、训练数据、关键假设。画出输入、模块、输出和损失。

第三遍：看证据

看 baseline、指标、主结果、消融、可视化、失败案例和局限性。

论文部分 要回答的问题 写作提醒
Abstract 问题、方法、结果、意义 不要堆背景，要让读者一眼知道贡献。
Introduction 为什么这个问题重要，现有方法缺什么 用真实需求和失败案例引出动机。
Method 你到底提出了什么 模块、公式、训练目标、复杂度要说清。
Experiments 怎么证明有效 数据集、baseline、指标、实现细节、消融缺一不可。
Ablation 每个贡献是否必要 去掉模块、替换模块、改参数，看性能变化。

把一个项目写成论文：从“我做了模型”到“我证明了问题”

课程项目和论文的区别，不在于模型名字有多高级，而在于你是否提出了清楚的问题，并用严谨实验证明你的方法有效。一个能写论文的项目通常包含：明确任务、强 baseline、合理改进、可靠实验、消融分析、失败案例和局限讨论。

Introduction 怎么写

先讲真实需求：为什么这个任务重要。再讲现有方法：它们解决了什么，但还缺什么。然后讲你的观察：例如小样本场景下模型不稳定，RAG 对版本更新文档容易引用过期内容，医学影像模型跨医院泛化差。最后自然引出你的方法。

Method 怎么写

方法部分要让别人能复现。不要只写“我们引入注意力机制”，而要说清输入是什么、模块怎么计算、输出是什么、损失函数怎么定义、训练流程怎么走。如果有多个模块，最好画一张流程图，并解释每个模块对应哪个问题。

Experiments 怎么写

实验部分要回答四个问题：和谁比，在哪比，用什么指标比，为什么可信。baseline 要足够强；数据集要说明规模、划分、标签和预处理；指标要符合任务目标；实现细节要包括模型、学习率、batch size、训练轮数、硬件或主要环境。

Ablation 怎么写

消融实验不是凑表格，而是验证你的贡献。去掉新模块、替换关键设计、改变超参数、换数据集，都可以帮助读者理解方法为什么有效。好的消融能让审稿人相信：提升不是偶然，也不是调参堆出来的。

Conclusion 和 Limitation 怎么写

结论要克制，说明你解决了什么、结果如何、意义是什么。局限不是自我否定，而是科研诚实：数据规模有限、只验证了某些领域、推理成本较高、对噪声敏感。这些局限也能成为后续工作。

12. 大厂求职与面试

面试不是背标准答案，而是证明你知道“为什么选这个模型、怎么验证有效、失败怎么排查”。

项目表达模板：背景：解决什么问题；方法：用了什么模型；难点：数据、训练、指标或工程难点；优化：做了哪些改进；结果：指标提升多少；复盘：为什么有效，失败案例是什么。
1. 过拟合怎么解决？
加数据、数据增强、正则化、Dropout、Early Stopping、减小模型、交叉验证。加分点是先看学习曲线，判断是不是数据不足或模型过强。
2. 为什么要划分验证集？
验证集用于模型选择和调参，测试集用于最后评估。没有验证集，就容易把测试集调成“训练的一部分”。
3. 逻辑回归和线性回归区别？
线性回归预测连续值，用 MSE 等回归损失；逻辑回归输出概率，常用于分类，用交叉熵或极大似然训练。
4. 决策树、随机森林、GBDT 区别？
决策树单模型可解释但易过拟合；随机森林并行训练多棵树降低方差；GBDT 串行训练，每棵树修正前面错误，通常表格数据更强。
5. BatchNorm 和 LayerNorm 区别？
BatchNorm 主要沿 batch 统计，常见于 CNN；LayerNorm 对单样本内部特征归一化，常见于 Transformer，对 batch size 不敏感。
6. Dropout 为什么有效？
训练时随机丢弃部分神经元，降低共同适应，类似训练多个子网络，提升泛化。
7. Adam 和 SGD 区别？
SGD 简单直接，可能泛化好但调参敏感；Adam 自适应学习率，收敛快。AdamW 改善权重衰减处理，是很多深度模型常用选择。
8. Transformer 为什么有效？
自注意力能建模全局依赖，多头机制从不同子空间看关系，并行性好，预训练和迁移能力强。
9. Attention 的 Q/K/V 是什么？
Query 是“我想找什么”，Key 是“我有什么标签”，Value 是“真正取走的信息”。Q 与 K 算相似度，再对 V 加权求和。
10. 如何做消融实验？
去掉或替换一个模块，保持其他设置不变，对比指标变化；还可以做参数敏感性、复杂度和不同数据集验证。
11. 类别不平衡怎么办？
重采样、类别权重、Focal Loss、阈值调整、使用 PR-AUC/F1/Recall 等更合适指标，并结合业务代价。
12. RAG 为什么能减少幻觉？
因为回答前先检索外部知识，把生成过程约束在相关资料上。但如果检索差或引用不准，仍然会产生错误答案。
13. LoRA 的直觉是什么？
冻结大模型主体，只训练低秩适配矩阵，用少量参数学习领域变化，节省显存和训练成本。
14. 线上效果比离线差怎么办？
检查数据泄漏、分布偏移、特征实时性、指标不一致、样本延迟、线上日志和阈值策略。
15. 怎么讲一个项目的难点？
不要只说“用了模型”。要讲数据难点、指标选择、baseline、错例、优化、消融、部署成本和复盘。
16. 为什么 LightGBM 在表格数据上常很强？
它能高效处理非线性、特征交互、缺失值和不同尺度特征，训练快、调参成熟，在结构化业务数据上常比深度模型更稳。
17. 什么时候不用深度学习？
数据很少、特征结构清楚、解释性要求高、延迟和成本严格时，线性模型、树模型或规则系统可能更合适。
18. 如何判断模型欠拟合还是过拟合？
看训练集和验证集曲线：两者都差多半欠拟合；训练好验证差多半过拟合；训练不稳定要看学习率、数据和梯度。
19. 为什么要固定随机种子？
为了提升实验可复现性。深度学习训练、数据切分、初始化和采样都有随机性，论文最好报告多次运行均值和方差。
20. 什么是数据泄漏？
训练时使用了真实预测时拿不到的信息，比如把未来信息、测试集统计量或标签相关字段放进特征，会导致离线分数虚高。
21. 为什么验证集调参后还要测试集？
验证集已经参与模型选择，性能会被乐观估计；测试集保留给最终评估，模拟未知数据表现。
22. CNN 的卷积核在学什么？
低层可能学边缘、纹理和局部形状，高层组合成更抽象的目标部件或语义模式。
23. 为什么 Transformer 需要位置编码？
自注意力本身不天然知道 token 顺序，位置编码给模型提供序列位置信息。
24. 什么是梯度消失和梯度爆炸？
反向传播时梯度在多层中变得极小或极大，导致学不动或训练崩溃。可用归一化、残差连接、合适初始化和梯度裁剪缓解。
25. 为什么残差连接有效？
它给信息和梯度提供更直接的通路，缓解深层网络训练困难，让模型学“增量修正”而不是每层重学全部变换。
26. Embedding 好坏怎么评估？
看下游任务表现、近邻检索质量、聚类可分性、可视化、人工评估，以及是否存在偏见或领域漂移。
27. RAG 系统该怎么评测？
分开看检索和生成：检索看 Recall@K、MRR、引用命中；生成看事实性、完整性、引用一致性、人工偏好和延迟成本。
28. Agent 最容易出什么问题？
计划错误、工具调用参数错、执行结果不验证、循环卡住、权限过大。要加任务边界、日志、检查点和可回滚机制。
29. LoRA 和全量微调怎么取舍？
LoRA 成本低、适合多领域适配和资源有限场景；全量微调自由度更高但成本大、风险高。要看数据量、算力、目标和部署方式。
30. 论文里的 baseline 应该怎么选？
至少包括经典强方法、当前主流方法和与你最接近的方法。baseline 不能刻意选弱，否则贡献不可信。

15. 术语表与速查表

遇到论文和面试里的关键词，先把它放回任务、数据、模型、损失、优化和评估这六个位置。

术语 英文 一句话解释
样本Sample一条用于训练或评估的数据。
特征Feature描述样本的信息，比如年龄、词向量、像素。
标签Label监督学习中希望模型预测的答案。
模型Model从输入到输出的可学习函数。
参数Parameter模型训练中被更新的权重。
超参数Hyperparameter训练前人为设定的配置，比如学习率。
损失函数Loss Function衡量预测和真实答案差距的函数。
梯度Gradient告诉参数往哪个方向改能让损失下降。
学习率Learning Rate每次参数更新的步子大小。
训练集Training Set用来学习参数的数据。
验证集Validation Set用来调参和选模型的数据。
测试集Test Set最后报告泛化性能的数据。
欠拟合Underfitting模型太弱，训练集也学不好。
过拟合Overfitting模型记住训练集细节，泛化差。
泛化Generalization模型在未见数据上的表现。
偏差Bias模型假设过强导致的系统性错误。
方差Variance模型对数据扰动过于敏感。
正则化Regularization限制模型复杂度以提升泛化。
交叉熵Cross Entropy分类任务常用损失。
准确率Accuracy预测正确的比例。
精确率Precision预测为正的样本里有多少是真的正。
召回率Recall真实为正的样本里找回了多少。
F1F1 ScorePrecision 和 Recall 的调和平均。
AUCArea Under Curve衡量排序区分能力的指标。
批量Batch一次送入模型的一组样本。
轮次Epoch完整遍历训练集一次。
反向传播Backpropagation沿计算图反推梯度。
优化器Optimizer根据梯度更新参数的方法。
DropoutDropout随机丢弃神经元的正则化方法。
BatchNormBatch Normalization按 batch 统计做归一化。
LayerNormLayer Normalization按单样本特征维度做归一化。
卷积Convolution用局部窗口提取模式。
注意力Attention根据相关性分配信息权重。
TransformerTransformer以自注意力为核心的模型架构。
预训练Pretraining先在大规模数据上学通用能力。
微调Fine-tuning在特定任务或领域上继续训练。
EmbeddingEmbedding把对象映射成向量表示。
RAGRetrieval-Augmented Generation检索外部资料后再生成答案。
AgentAgent能规划步骤并调用工具的模型系统。

蒸馏Distillation用大模型指导小模型学习。
消融实验Ablation Study去掉模块验证其贡献。
